Проверено на Java 21.0.10, Maven 3.9.16 и отдельном локальном PostgreSQL 18.3, порт 55439. Существующая пользовательская БД на 5432 не изменялась.

SQL-проверки воспроизводят ошибки отрицательного пробега/счётчика, неизвестного поезда/ресурса, нулевого интервала, пересечения рейсов и присутствия, изменения использованной версии правил, неизвестного сценария, изменения/удаления/очистки snapshot.
Также проверены разрешённое касание границ, раннее ТО с зачётом более позднего номинального рубежа, сохранение frozen work, одинаковый hash после перестановки записей/смены часового пояса, новый hash после изменения рейса/счётчика, сохранность старого снимка.

Проверки не доказывают корректность неподтверждённых бизнес-правил, интеграцию E3 с планировщиком, независимую валидацию D2 или достижение KPI готовности парка. Формат канонизации `pg-jsonb-text-v1` предложен для согласования, не объявлен утверждённым общим DTO.
