# Интеграция database с main, PR #6

Объединены database 7d3c776 и main 891a426, включая иконки из последнего коммита.
Девять исходных конфликтов и два пересечения последнего коммита разрешены
с сохранением функций обеих веток: ролей, оформления, журнала диспетчера,
карточки состава, E2-планировщика, независимой проверки D2 и оперативного
сценария отказа FULL43.

Главная планировщика и технолога предлагает FULL43; оперативный блок расположен
перед таблицей парка. Диспетчер сохраняет свой отдельный экран. Сообщение в
журнале диспетчера само по себе не запускает оперативную замену: она оформляется
отдельным проверяемым решением в FULL43.

Согласование доступно планировщику только при PASS D2 для текущих источника,
версии и событий плана. Устаревшая оговорка «согласовать без проверки» удалена
из UI и документации. Тесты новых модулей получили роли согласно серверной
политике main; проверка доступа сохранена.

Проверено на Java 21 и отдельной PostgreSQL 18.3: mvn verify — 97 тестов,
0 failures, 0 errors, 0 skipped. Frontend production build успешен.
OpenAPI YAML разобран, все 64 локальных ссылки разрешаются.
Через интерфейс проверены замена CASE-01 на CASE-42 с дефицитом резерва и
E2-расчёт: D2 PASS, 12/12 работ, 36 составо-часов, 0 конфликтов с 252 рейсами.

Полный E3-план на 14 суток и КЭГ этим слиянием не добавлены. Новая миграция V4
сохраняется; V1–V3 не менялись. Рабочий Docker-volume команды не очищался.
